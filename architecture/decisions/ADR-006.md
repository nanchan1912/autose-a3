# ADR-006: Sonnet 5.5 for analyst, implementer and tester; Opus 5.5 for the reviewer

Status: Accepted
Date: 2026-11-24
Decision: D6 (Models)

## Context

Each role can use a different model. Prices per million tokens (input/output): Opus 5.5 $4/$20,
Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50.

## Decision

- Analyst, implementer, tester: `claude-sonnet-5-5`, effort medium.
- Reviewer: `claude-opus-5-5`, effort high.
- Models are set per variant in `workflow/variants.json`.

## Alternatives considered

- **Opus everywhere.** Rejected: it would increase costs without necessarily providing proportional
  improvements across all stages.
- **The same model for authors and reviewer.** Tested as variant `E1-same-model` (experiment E1).

## Consequences

- The authoring stages need capable reasoning but can be done cost-effectively on Sonnet.
- The more expensive Opus model is reserved for the reviewer, because reviewing code requires careful
  reasoning and identifying subtle mistakes.
- A different model for the reviewer also supports reviewer independence (ADR-008).
- A local plumbing run on Haiku 5.5 completed stages 1-4 for issue I1 for $0.035, so Haiku is a
  possible cheaper option that was not chosen for the real runs.
