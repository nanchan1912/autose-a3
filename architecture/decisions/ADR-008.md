# ADR-008: The reviewer is independent by construction

Status: Accepted
Date: 2026-11-24
Decision: D8 (Reviewer independence)

## Context

The brief requires a reviewer that sees only the issue, the diff and the repository at the PR head,
not the implementer's conversation or reasoning, and that can read and run code but not push. A
reviewer that simply agrees with the implementer adds nothing.

## Decision

- **Separate job** (`autose-review.yml`) on a fresh runner. It downloads none of the build job's
  artifacts, so spec, design, implementer notes and transcripts are not available to it.
- **Different model** (Opus 5.5, ADR-006) and its own prompt (`workflow/prompts/review.md`).
- **Restricted permissions:** the agent step has no GitHub token, the job has `contents: read`, and
  the agent has no Edit/Write tools. A separate step posts the result as a `COMMENT` review, which can
  never count as an approval.
- **Evidence required:** the reviewer derives the requirements from the issue itself, runs its own
  probes and the test suite, and must give evidence (command and output, or code line) for every
  finding. The verdict is computed by code from those findings (ADR-007).
- **Measured on known cases:** 5 seeded PRs (3 with planted defects that pass the existing tests,
  2 clean; ground truth in `experiment/seeded_prs/labels.json`).

## Alternatives considered

- **Reviewer in the same job or conversation as the implementer.** Rejected: it would be influenced
  by the implementer's reasoning or confidence.
- **Same model as the implementer** (`E1-same-model`) and **reviewer sees the author's rationale**
  (`E1-sees-rationale`): tested in experiment E1.

## Consequences

- Reviewer independence is the most important design consideration: the reviewer evaluates the
  actual code and evidence rather than the implementer's reasoning or confidence.
- Separate job, different model, restricted permissions and required evidence reduce bias and
  prevent automatic approvals; the seeded PRs show whether this is effective.
- The separate job costs runner time and repeats the project installation.
