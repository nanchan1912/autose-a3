Hi, I'm using `toc` together with `footnotes` for a long document and some of the table of contents entries are missing words.

Minimal example:

```python
import markdown
md = markdown.Markdown(extensions=['toc', 'footnotes'])
md.convert('# *Gamma* x[^1] y\n\n[^1]: note\n')
print(md.toc_tokens[0]['name'], md.toc_tokens[0]['id'])
```

I get `Gamma y` and `gamma-y`. I expected `Gamma x y` and `gamma-x-y`: the footnote marker itself should not be in the TOC, but the word `x` is real heading text and it just disappears. The same happens in the `id` of the `<h1>` in the HTML output, so my old links to `#gamma-x-y` are broken.

It only seems to happen when there is some inline markup (emphasis, bold, code) before the footnote reference in the same heading. Headings without footnotes are fine.

Version: current master. Python 3.13.
