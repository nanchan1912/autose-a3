Most wikis let you write `[[Some Page|the text you see]]`. With the `wikilinks` extension that syntax is not recognised at all, the brackets just stay in the output.

What I'd like:

- `[[Some Page|the label]]` links to the same URL as `[[Some Page]]` (so `/Some_Page/` with the defaults) but shows `the label` as the link text.
- The URL must still come from the page name only. All the options that change the URL or the link (`base_url`, `end_url`, `html_class`, a custom `build_url`, and the `wiki_*` values from the `meta` extension) should work exactly the same for links with a label. A custom `build_url` should get the page name, not the label.
- The label can contain any characters except `|` and `]`.
- If the label is empty or only spaces (`[[Some Page|]]`), just show the page name.
- Plain `[[Some Page]]` links must not change.
