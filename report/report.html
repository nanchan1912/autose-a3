AutoSE Assignment 3: an agentic issue-to-pull-request workflow

Repository: https://github.com/nanchan1912/autose-a3 (Python-Markdown pinned at 3f2c551). All runs, PRs and reviews: results/runs.md. ADRs: architecture/decisions/.

1. Architecture

A label autose or a comment /autose by a maintainer starts autose.yml: a gate job (authorisation, command parsing), then up to three rounds (reusable autose-round.yml), then finalize. In a round, a Python orchestrator runs stages 1-4 as a fixed state machine with three agents and a deterministic check after every stage, then pushes the branch and opens the PR (stage 5, no agent); ci.yml and a release check follow; the independent reviewer runs in its own job (autose-review.yml, stage 6). If it requests changes, the next round resumes at the stage its findings point to. Agents are headless Claude Code processes with fixed tool allow lists, JSON output schemas, turn and dollar limits; none of them holds a GitHub token.
